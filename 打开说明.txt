7/∞ 工厂 · 七分厂 —— 网站工程打开说明
========================================

一、这是什么
------------
这是一个 React + TypeScript + Vite 网站工程，包含星期一到星期日共 7 个页面。
- src/pages/          每一天的页面源码（Monday ~ Sunday + Home）
- src/data/           工资条等数据
- public/、dist/      图片资源与已构建好的成品
- 其余为配置文件

二、怎么运行（正规做法）
----------------------
前提：电脑装了 Node.js（18 或更高版本），没有的话先装 nodejs.org 的 LTS 版。

1. 解压本压缩包到一个文件夹
2. 打开命令行（cmd 或 PowerShell），进入该文件夹
3. 执行：
     npm install
   （需要从网络下载依赖，约 1~3 分钟）
4. 执行：
     npm run dev
5. 浏览器会自动打开 http://localhost:3000 看到网站

三、在 Kimi 里打开（推荐）
-------------------------
把解压后的文件夹作为工作区，直接对 Kimi 说：
  “运行这个网站”
Kimi 会自动执行安装依赖和启动，并给出预览。

四、只是看一眼，不想装环境
--------------------------
压缩包里带了 dist/ 文件夹（已构建成品），
用任意静态文件服务器指向 dist 即可预览；
但注意直接访问子页面（如 /friday）需要服务器支持
单页应用回退，不建议用 file:// 直接双击打开。

五、常见问题
------------
Q: npm install 报错？
A: 检查 Node 版本（node -v 需 >= 18），和网络是否正常。

Q: 端口 3000 被占用？
A: 执行 npm run dev -- --port 5173 换端口。

Q: 修改后怎么生效？
A: 开发模式下保存文件即自动刷新；正式发布执行 npm run build，
   产物在 dist/ 文件夹。
